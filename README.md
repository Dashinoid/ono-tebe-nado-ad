# Оно тебе надо

Проектная работа Яндекс Практикума: страница аукциона по макету.

https://github.com/Dashinoid/ono-tebe-nado-ad

## Запуск

Откройте index.html в браузере. Сервер и установка зависимостей не требуются.

## Технологии

HTML, CSS, Flexbox, Grid, локальные шрифты Raleway. Ширина макета — 1100 px.

## Структура

- index.html — разметка страницы.
- styles/ — стили.
- fonts/ — шрифты.
- images/ — изображения и логотипы.
